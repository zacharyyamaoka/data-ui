# The bar, Shopify's way: three elements

The same 1,149 actuators under `toolbar="bar" views="dropdown" promote=""`: the bar is exactly three elements, as
Shopify admin's index tables are: the saved-view chip on the left, the search box, and Display on the right, which holds
everything else (layout, frame, properties, filter, sort, group). Select rows and the bulk band takes the column header
row's place, tinted, with "N selected", the actions and "Show only selected".

- **App:** robotparts
- **Replaces:** Shopify admin's index table bar ("All ⌃⌄ · Search and filter · columns") and its bulk-action band
  (zach_brain Sources … images 86 and 87, 2026-10-26).
- **Shows:** `views="dropdown"`, `promote=""` (nothing promoted), `display="popover"`, `selectable`, the bulk band.
- **Data:** `../robotparts-actuators/actuators.json` (the robotparts-actuators case's file).
