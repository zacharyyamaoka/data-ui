Filter kinds

Each kind is one facets: entry, {property, as: <kind>, …options}, and every kind edits the same Bases filters tree, so a pick shows in every view and what the rail cannot draw stays as a custom clause. An unknown kind draws as values with a warning. Options common to all: label, info (the ⓘ), diagram, collapsed. The snippets below are cut from this case's views.base. Sites accessed 2026-10-26.

values copies Algolia refinementList

checkboxes with counts, "Show N more", a find box over a long list; counts are disjunctive. Options: label, limit, sort (count | alpha | value), searchable, exclude. Try it: ?brand=Steadywin,CubeMars

facets:
  - { property: brand, as: values, exclude: true, label: Brand, searchable: true }

values + exclude copies Kibana's filter pills, Exclude results

a ⊘ beside each value writes {not: [p == v]}; the value is struck through. Options: exclude: true. Try it: ?brand!=KST,Feetech

facets:
  - { property: brand, as: values, exclude: true, label: Brand, searchable: true }

select copies Algolia menu / menuSelect

one value or Any, as radio buttons or (dropdown: true) a select. Options: any, dropdown, limit, sort. Try it: ?in_stock=no

facets:
  - { property: in_stock, as: select, label: Stock }

toggle copies Algolia toggleRefinement

a switch for one value ("In stock only", "Has CAD"); Algolia's on is value: here. Options: value (default true), text. Try it: ?in_stock=yes

facets:
  - { property: in_stock, as: toggle, value: "yes", text: In stock only }

has copies Tableau quick filters' Special (null / non-null)

has a value, for one property or a group, matching all of or any of. Options: properties, match (all | any). Try it: ?hasany=photo,price

facets:
  - { property: photo, as: has, properties: [photo, torque_density, price], label: Has data, match: all }

range copies Algolia rangeInput; Zillow's min / max dropdowns (choices:)

min and max boxes (dates on a date property), or dropdown pairs of round numbers. Options: unit, choices, diagram. Try it: ?price=100..500

facets:
  - { property: price, as: range, choices: [25, 50, 100, 250, 500, 1000, 2500], label: Price (min / max) }

facets:
  - { property: mass, as: slider, log: true, label: Mass }

facets:

facets:
