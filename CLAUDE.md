# data-ui

A drop-in kit for viewing any data: framework-free custom elements (`<data-views>`, `<data-facets>`, `<data-value>`), one view grammar (Obsidian Bases `.base` files) and `--data-*` tokens. Read `docs/SPEC.md` (the design) and `docs/CONTRACT.md` (what every view and host builds against; changing it is a barrier) before changing anything; `README.md` has the commands (`npm run build`, `npm test`).
